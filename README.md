💻 Cartão de Visitas — Erik Canguçu
Um cartão de visitas digital desenvolvido com HTML, CSS e JavaScript, com design moderno, e links para redes sociais.

📸 Sobre o projeto
Este projeto foi criado com o objetivo de praticar os fundamentos do desenvolvimento web front-end, explorando a estruturação de páginas, estilização com CSS e interatividade com JavaScript.

O cartão apresenta informações pessoais e links de contato em uma interface simples, responsiva e visualmente agradável.

✨ Funcionalidades

☀️ Modo diurno: interface com cores claras e imagem de fundo.
🌙 Modo noturno: interface com cores escuras e imagem de fundo alternativa.
🔗 Links de contato: acesso ao GitHub, LinkedIn e e-mail.

🛠️ Tecnologias utilizadas

HTML5 — estrutura e conteúdo da página.
CSS3 — layout, cores, imagens de fundo, responsividade e efeitos visuais.
JavaScript — alternância de temas e armazenamento da preferência do usuário.
